Әр оқушыға жеке ұпай қойыңыз. Бұл әзірге мұғалім браузеріндегі сынақ нұсқасы: ұпайлар жергілікті сақталады, Supabase серверіне жіберілмейді. Нақты сабақтың ресми 10 ұпайлық нәтижесіне қосу үшін серверлік бағалау әрекеті қажет.

Нәтижелерді жүктегеннен кейін оқушылар пайда болады.

⚙ Ортақ деректер базасын қосу

Әртүрлі құрылғыдан деректер алмасу үшін Supabase жобасының URL және anon/public key мәндерін енгізіңіз. Құпия service_role кілтін ешқашан браузерге енгізбеңіз.

Алдымен төмендегі SQL файлын Supabase SQL Editor ішінде іске қосыңыз.

Қосу реті

  1. supabase.com сайтында жоба ашыңыз.
  2. Жобаңыздың SQL Editor бөліміне берілген database_setup.sql кодын орындаңыз.
  3. Project URL мен anon/publishable key енгізіп, «Қосылу» батырмасын басыңыз.
  4. Сессияны қайта ашыңыз. Мұғалім мен оқушы әртүрлі құрылғыдан сол кодпен қосыла алады.
